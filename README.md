\# PantryPal



An intelligent AI-driven kitchen management and commercial culinary operations platform.



\## Architecture

\- \*\*Frontend:\*\* React.js

\- \*\*API Gateway:\*\* Spring Cloud Gateway

\- \*\*Microservices:\*\* Spring Boot 3 (Auth, Inventory, AI Engine, Restaurant Ops)

\- \*\*Database:\*\* MySQL

\- \*\*Orchestration:\*\* Docker Compose
